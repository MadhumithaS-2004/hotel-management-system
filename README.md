# 🏨 StayEase — Hotel Management System

A web-based Hotel Management System built with HTML, CSS, and JavaScript as part of my Database Management System coursework.

## Features
- Room management with availability tracking
- Booking system with check-in / check-out flow
- Guest records management
- Billing and invoice generation
- Reports with CSV export
- Real-time occupancy dashboard

## Tech Stack
HTML · CSS · JavaScript (Vanilla)
